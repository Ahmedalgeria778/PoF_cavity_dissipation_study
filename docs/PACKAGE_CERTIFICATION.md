The scripts are all committed; the large field archives they read are not, and each set has a committed index that names it by filename, byte size and SHA-256 checksum, so a copy obtained from the corresponding author can be verified before the scripts are re-run:

That manifest is written by `scripts/manifest_fig4_fields.py`, which also recomputes from those fields the peak and interior-mean strain-rate magnitudes quoted in Main Sec. 5.3 and fails if they no longer match.

The dissipation values quoted for those three controls have committed records independently of the fields: `results/p1_gci_iso/p1_gci_raw.csv` (read by `scripts/make_fig_gci.py`) and `results/p1_gci_iso/p1_gci_summary.csv` (read by `scripts/export_legacy_supp_tables.py`).
