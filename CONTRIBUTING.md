# Contributing to PoF_cavity_dissipation_study

Thank you for your interest in contributing to this research repository!

## How to Contribute

### Reporting Issues

If you find any issues with the code, data, or documentation:

1. Check the existing issues to avoid duplicates
2. Create a new issue with a clear description
3. Include steps to reproduce if applicable
4. Specify your environment (OS, Python version, etc.)

### Suggesting Improvements

We welcome suggestions for:

- Code optimization
- Documentation improvements
- Additional analysis scripts
- Data visualization enhancements

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Code Style

- Python: Follow PEP 8 guidelines
- LaTeX: Use consistent formatting
- Comments: Write clear, concise comments in English
